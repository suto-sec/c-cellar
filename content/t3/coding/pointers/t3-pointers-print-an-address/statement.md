# Print an address

Declare `int x = 42;` and `int *p = &x;`. Print two lines: `p=<the address stored in p>` (use `%p`; the program does not need to show the same address every time, which is why the checker only looks at its shape) and `*p=<the value p points to>`.

**Example**

```
p=0x7ffc1d2a5c34
*p=42
```
