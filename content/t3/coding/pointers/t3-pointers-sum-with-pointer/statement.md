# Sum with a pointer

A hidden `main` reads `n` and then `n` integers, and prints `sum=<result>`. Write in `answer.c` a function that walks the array with a **pointer you increment** (not with `v[i]`):

```c
int sum(const int *v, int n);
```

**Example**

Input:
```
3
4 5 6
```
Output:
```
sum=15
```
