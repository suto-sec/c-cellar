# Reverse in place with two pointers

A hidden `main` reads `n` and `n` integers, calls your function and prints the array. Write in `answer.c`, using **two pointers** that move towards each other:

```c
void reverse(int *v, int n);   /* reverses the array in place */
```

**Example**

Input:
```
4
1 2 3 4
```
Output:
```
4 3 2 1
```
