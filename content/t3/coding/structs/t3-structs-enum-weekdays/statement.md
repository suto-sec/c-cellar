# An enum of days

Define `enum day { MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY };`. Read a number from 0 to 6 and print `<day> -> <next day>` (after Sunday comes Monday). Any other number prints `invalid`. Keep the names in an array indexed by the enum.

**Example**

Input:
```
2
```
Output:
```
Wednesday -> Thursday
```
