# Inventory value

Read `n` (1 to 50) and then `n` lines `name quantity price`. Store them in an array of structs. Print the total value (sum of quantity x price) with two decimals and the name of the item with the highest unit price (the first one if there is a tie), in the format shown.

**Example**

Input:
```
2
pen 10 1.50
book 2 12.25
```
Output:
```
total=39.50
most expensive: book
```
