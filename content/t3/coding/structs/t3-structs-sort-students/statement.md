# Sort records

Read `n` (1 to 50) and then `n` lines `name score`. Print them sorted by score, **highest first**; students with the same score are sorted by name in alphabetical order. Use `qsort` with your own comparison function. Format: `name: score`.

**Example**

Input:
```
3
bob 70
ann 90
cid 70
```
Output:
```
ann: 90
bob: 70
cid: 70
```
