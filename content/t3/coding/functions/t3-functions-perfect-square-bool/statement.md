# Perfect square?

Write a function `bool is_square(int n)` that tells whether `n` is a perfect square (0, 1, 4, 9, 16, ...). Use the type `bool` of `<stdbool.h>`. The input has non-negative integers, one per line, until it ends: for each one print `<n> yes` or `<n> no`.

**Example**

Input:
```
16
17
```
Output:
```
16 yes
17 no
```
