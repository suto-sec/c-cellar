# Prototype before main

Write a **complete program** whose function `average` is defined **after** `main`. Put its prototype before `main`:

```c
double average(int a, int b);   /* (a + b) / 2 as a double */
```

`main` reads two integers and prints the average with one decimal (for `3 4` that is `3.5`).

**Example**

Input:
```
3 4
```
Output:
```
3.5
```
