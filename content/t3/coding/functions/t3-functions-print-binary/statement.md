# Print in binary

A hidden `main` reads unsigned integers and prints each in binary on its own line. Write in `answer.c`, **with recursion** (no arrays):

```c
void print_binary(unsigned n);   /* prints the binary digits of n without leading zeros; 0 prints "0"; no newline */
```

**Example**

Input:
```
10
```
Output:
```
1010
```
