# Length and vowels

Read **one line** from standard input (use `fgets`) and print two lines:

```
length: <number of characters, not counting the final newline>
vowels: <number of vowels a e i o u, upper or lower case>
```

```
$ echo "Hello World" | ./prog
length: 11
vowels: 3
```

Spaces count as characters. An empty line has length 0.
