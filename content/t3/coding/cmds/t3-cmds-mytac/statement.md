# mytac

Write `mytac`, which prints the lines of **standard input** in reverse order: the last line first.

- The input can have **any number of lines** (up to 1000 characters each): do not use a fixed-size array.
- Every output line ends with `\n`, even if the last input line did not.

**Example**

```
$ printf 'one\ntwo\nthree\n' | ./prog
three
two
one
```
