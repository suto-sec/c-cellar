# Above the average

The input is `n` (1 to 100) followed by `n` integers. Print how many numbers are **strictly greater than the average** of all of them (the average is a real number: for `1 2 4` it is 2.33 and only `4` is above it).

**Example**

Input:
```
5
10 20 30 40 50
```
Output:
```
2
```
