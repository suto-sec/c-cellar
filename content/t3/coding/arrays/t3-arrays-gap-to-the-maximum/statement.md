# Gap to the maximum

The first number on the input is `n` (from 1 to 1000), followed by `n` integers. Declare the array **after** reading `n`, with exactly `n` elements (a variable-length array, allowed since C99). Print, on one line separated by single spaces, how far each number is from the largest one (`largest - number`).

**Example**

Input:
```
4
3 9 -2 9
```
Output:
```
6 0 11 0
```
