# A linked list

Read integers until the input ends. Store each one in a new **node** of a singly linked list, inserting every new node at the **front**. Then print the list from its first node, numbers separated by single spaces, and free all the nodes. (Reading `1 2 3` prints `3 2 1`.) With no input print an empty line.

**Example**

Input:
```
1 2 3
```
Output:
```
3 2 1
```
