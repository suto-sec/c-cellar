# Histogram of digits

Read integers between 0 and 9 until the input ends. Allocate the counters with `calloc` and print, for each digit from 0 to 9, how many times it appeared, in the format `digit: count`.

**Example**

Input:
```
1 1 2
```
Output:
```
0: 0
1: 2
2: 1
3: 0
4: 0
5: 0
6: 0
7: 0
8: 0
9: 0
```
