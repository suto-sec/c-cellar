# Aligned columns

Print a table of `n`, `n^2` and `n^3` for n = 1 to 5. Every value (and the header words) is **right-aligned in a column 5 characters wide**, with no other separators.

**Example**

```
$ ./prog
    n  n^2  n^3
    1    1    1
    2    4    8
    3    9   27
    4   16   64
    5   25  125
```
