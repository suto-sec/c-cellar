# Hello, arguments

Write a program that greets every command-line argument.

- For each argument, print `Hello, <argument>!` on its own line.
- With no arguments, print `Hello, world!`.

```
$ ./prog Ada Linus
Hello, Ada!
Hello, Linus!
$ ./prog
Hello, world!
```

An argument may contain spaces (`./prog "Grace Hopper"` is **one** argument).
