# How many digits?

The input has integers, one per line, until it ends. For each one print `<n> has <d> digit(s)` (`1 digit` for one digit, `<d> digits` otherwise; the minus sign of a negative number is not a digit). Use a **`do ... while`** loop to count the digits, so that `0` correctly has one digit.

**Example**

Input:
```
0
12345
```
Output:
```
0 has 1 digit
12345 has 5 digits
```
