# Stop at the first bad token

Read integers and add them up. If the input ends normally, print `sum=<total>`. If a token that is **not a number** is found, print `sum=<total so far> (stopped at bad input)` instead and stop reading.

**Example**

Input:
```
5 5 oops 5
```
Output:
```
sum=10 (stopped at bad input)
```
